# Ritesh Analytics Portfolio

Personal portfolio website for Er Ritesh Singh, built with React + TypeScript and styled with Tailwind + shadcn/ui.

## Features

- Landing page with section-based navigation
- Breadcrumb-style context (`Home > Section`)
- Dedicated sections for About, Experience, Education, Licenses, Projects, Skills, and Contact
- Themed UI with animated hero/visual elements
- Resume download action

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- React Router

## Getting Started

### 1) Install dependencies

```bash
npm install
```

### 2) Start development server

```bash
npm run dev
```

### 3) Build for production

```bash
npm run build
```

### 4) Preview production build

```bash
npm run preview
```

## Testing

```bash
npm run test
```

## Deployment

This project includes GitHub Pages deployment scripts:

```bash
npm run deploy
```

Make sure the repository settings are configured for GitHub Pages from the `gh-pages` branch.

## Project Structure

- `src/components` – reusable UI and section components
- `src/pages` – route-level pages
- `src/contexts` – theme and app context
- `public/images` – static images and assets
